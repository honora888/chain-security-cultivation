# Reentry Devourer Visual Bible

> Quest 1「噬灵回环兽」视觉设定基线。本文是后续美术、动效和前端实施规格，不代表相关正式资产已经完成或接入。

## 角色定位

噬灵回环兽是经典重入漏洞的拟兽化记忆锚点。它的危险不来自一次强力攻击，而来自“外部调用发生后，内部状态尚未更新”形成的可重复入口。形象必须让学习者在不阅读长文时也能记住三件事：

1. 身体形成没有闭合的自噬回路；
2. 回路上的状态更新节点是可被击中的弱点；
3. Checks、Effects、Interactions 三道阵印能够按顺序切断回路。

它属于水系、金丹期、High 风险，但不是水龙、海蛇、章鱼或西方龙的换色版本。气质应冷静、压迫、诡谲，避免血腥、卡通萌宠和抽卡手游式夸张。

## 视觉隐喻

| 合约事实 | 视觉转译 | 禁止误导 |
| --- | --- | --- |
| `withdraw()` 在余额清零前执行外部 `call` | 胸腹回环器官先向外放出灵流，尾端的“归零节点”仍保持点亮 | 不画成一次性爆炸或普通吐息 |
| `receive()` 再次调用 `withdraw()` | 外放灵流从兽首侧面的递归裂口回灌，沿身体内圈重新进入 | 不暗示真实 Monad 交易正在发生 |
| `balances[msg.sender]` 尚未清零 | 腹侧状态结晶保持水蓝，旁有“尚未清零”的文字证据 | 不只靠颜色传达 |
| 重复提款直至金库枯竭 | 多层回流残影沿同一闭环叠加，金库水位逐步下降 | 不使用无穷循环；教学回放有明确五步 |
| CEI 修复 | 三道阵楔按 Checks → Effects → Interactions 锁住三个断点 | 不把三步合并成一枚泛用法阵 |
| 本地 Boss HP | 兽体破损与封印程度的本地战斗表现 | 不描述为链上数据 |

## 轮廓与解剖

### 1. 整体轮廓

- 主体为横向偏椭圆的断环，头部位于左上四分之一，尾部从右下回卷至胸腹，但在弱点处保留一个清晰缺口。
- 展开状态的外轮廓约为宽高比 1.35:1；盘踞状态约为 1:1。任何姿态都应先读成“断开的回环”，其次才读成异兽。
- 躯体有前后两层：厚重的实体外环承担兽形，半透明的内环承担调用链和灵流。二者不能混成普通蛇身。

### 2. 头部结构

- 头部呈低扁楔形，前额宽、下颌短，避免长吻龙头。
- 额骨分为三片向后包覆的水晶甲片，中央甲片延伸至弱点导管。
- 两侧不是龙角，而是向内弯曲的“回流鳍冠”；鳍冠内侧有重复的同心刻度。
- 耳后保留两道短的回流腮裂，攻击时分别标示 `call` 与 `receive()` 的方向。

### 3. 眼睛样式

- 双眼为狭长的冷青瞳，瞳孔由两个相向旋转的短弧组成。
- 正常状态亮度低于弱点；暴走状态可增加冷紫外圈，但不得持续闪烁。
- 战败状态眼睛熄灭为灰青，不使用翻白眼或卡通眩晕符号。

### 4. 口部与吞噬器官

- 口腔不是血肉深洞，而是层叠的水压瓣膜，开合类似闸门。
- 上颚内侧有三层向内收束的半透明环片，表现重复“取款”而非撕咬。
- 咽喉中心为“递归裂口”：一个垂直的黑青水隙，边缘有冷青刻度；`receive()` 回调由此回灌。
- 牙齿数量少、形状偏玉质阵楔，不以尖牙密度制造恐怖感。

### 5. 躯干结构

- 外层由不规则甲鳞组成，鳞片沿回环方向递进变小；每隔七至九片出现一枚“调用节”。
- 内层是可见的半透明水脉，流线必须有方向性，不能只是装饰性发光纹。
- 胸腹有一枚扁圆状态结晶，代表 `balances[msg.sender]`。未清零时为水蓝实心，Effects 生效后转为透明银白。

### 6. 尾部结构

- 尾端不是尖尾，而是分叉的双叶“状态闸片”。两片合拢代表余额清零，分开代表重入窗口仍开放。
- 尾端回卷到胸腹结晶附近，但不直接咬住自身；闭环由灵流而非肉身完成。
- 缩小时尾端双叶仍需保持可见，避免退化成普通蛇尾。

### 7. 鳞片与表面纹理

- 外甲为深海蓝至黑青的湿润玉石感，粗糙度中等，不做金属机甲。
- 鳞片边缘以低饱和银青描边，只有当前调用节可短暂提高亮度。
- 半透明区域使用水玻璃与墨染扩散的混合质感；避免塑料、果冻或彩虹折射。
- 暗部仍保留鳞片层次，不能压成纯黑剪影。

### 8. 水流与灵力

- 默认水流沿身体外环顺时针缓慢移动；重入时外环顺时针、内环逆时针，形成“再次进入”的视觉冲突。
- 每条灵流必须有起点、终点和文字证据对应；装饰水纹不得穿过代码、余额或调用栈文本。
- 重入残影最多三层，透明度逐层降低，避免造成“实际只有三次重入”的错误暗示；文字继续标注“重入次数 > 1”。

### 9. 弱点位置

- 弱点固定在胸腹状态结晶与尾端闸片之间，位于断环缺口的下缘。
- 视觉形态是一枚被水脉穿过的方形玉扣，中心刻有未闭合的小圆环。
- ACT3 识破后才完整显现；此前只能有低对比轮廓，避免提前泄题。
- 代码行 `balances[msg.sender] = 0` 与该玉扣建立一一对应的高亮连线。

### 10. 阵法封印位置

- Checks 阵楔锁在额部调用入口，阻止无效提款。
- Effects 阵楔锁在胸腹状态结晶，令余额先归零。
- Interactions 阵楔锁在咽喉递归裂口，使外部调用最后发生。
- 三印通过一条银青折线连接；顺序不可互换，阵线不得盖过代码 Diff。

### 11. 与常见水兽的区别

| 常见误读 | 必须避免 | 噬灵回环兽的替代特征 |
| --- | --- | --- |
| 水龙 | 长吻、鹿角、四足、祥云式龙身 | 低扁楔头、回流鳍冠、无足断环 |
| 水蛇 | 单一连续长身、尖尾 | 双层躯体、胸腹状态结晶、双叶状态闸片 |
| 章鱼 | 触手辐射、吸盘 | 单一主环与少量回流残影，无触手 |
| 普通鱼兽 | 鱼鳍、完整尾鳍、横向游泳姿态 | 尾端是状态闸片，姿态围绕递归缺口组织 |
| 西方龙 | 翼、厚重四肢、火焰口腔 | 无翼无足、水压瓣膜口腔、玉石阵楔 |

### 12. 缩略图识别特征

在 48×48 头像中至少保留：

1. 断环轮廓与右下缺口；
2. 额部双弧冷青瞳与回流鳍冠；
3. 胸腹方形状态玉扣。

头像不得依赖细鳞、文字或外部法阵才能辨认。

## 识别特征

### 稳定特征

- 断环缺口始终位于右下至下方区域；
- 头部始终位于环形左上侧并朝向内圈；
- 胸腹状态玉扣始终位于断环缺口内侧；
- 双叶状态闸片始终与玉扣相对；
- 主色冷青蓝，危险态只在裂口和眼圈加入冷紫或暗红。

### 可变特征

- 水流强度、残影数量、鳞片亮度；
- 阵印是否出现及点亮程度；
- 身体盘踞、前探、受击后仰和消散姿态；
- 背景水雾和地面涟漪。

### 连续性规则

不同状态不得改变头骨比例、鳍冠方向、缺口位置和状态玉扣形状。参考图中出现过水龙、狮兽和长蛇之间切换的问题，正式资产必须以本设定为唯一角色母版。

- Danger、Success、Warning 均需文字标签、边框或形状辅助，不单靠色相。

## 弱点与封印

### 弱点显现规则

1. ACT1–ACT2 只显示玉扣轮廓，不显示“弱点”标签；
2. ACT3 全部正确后，代码证据与玉扣之间出现一条短的银青连线；
3. ACT4 保持弱点可见，并用文字说明“余额尚未清零”；
4. ACT5 Effects 阵楔落位时，玉扣由实心水蓝切换为透明银白；
5. ACT5 完成后，断环缺口被三段阵线固定，Boss HP 才归零。

### CEI 三印形态

- Checks：窄盾形阵楔，刻一条向内收束的检查线；
- Effects：方形玉扣，刻闭合圆环，与状态结晶同形；
- Interactions：闸门形阵楔，刻向外单向箭头；
- 三印使用相同银白材质、不同轮廓，不使用英文首字母作为唯一识别。

## 异兽志与徽记

### 异兽志

- 画面以水墨断环为中心，右侧放结构批注，避免整页满彩战斗插画；
- 画像保留状态玉扣、递归裂口和断环缺口；
- “已收录并封印”属于本地学习记录，必须与 Monad Testnet 状态分离；
- 条目图可使用 4:3 或 1:1 构图，移动端优先 1:1；
- 卷轴边框是容器资产，不能把文字烘焙进图片。

### 水系守护者徽记

- 外轮廓为三枚阵楔围成的圆角三角；
- 中心为噬灵回环兽断环剪影，胸腹玉扣居中；
- 主色水蓝与银白，柔和金色只描边；
- 本地解锁动画与链上 `badgeBalance` 核验必须是两个独立状态；
- 徽记图内不出现“已铸造”文字，状态由 UI 文案表达。

### 加载与压缩

- 首屏只预加载背景和待机图；其他状态按幕次懒加载；
- 普通 UI 不使用当前参考图这类约 1.8–3.1 MB 的未优化 PNG；
- 使用 `next/image` 固定 `width`、`height`，桌面 Boss 图建议 `sizes="(max-width: 767px) 92vw, (max-width: 1023px) 70vw, 52vw"`；
- 首屏主体建议压缩后不超过约 350 KB，背景建议不超过约 450 KB；以实际视觉质量和性能测试为准；
- 透明资源优先 WebP；只有边缘或浏览器兼容性不满足时使用 PNG；
- 加载失败时显示 Loading / Disabled 断环线稿和可读名称，不显示空白框。

## 动画表现

### 角色动画层级

- Level 1：轻微漂浮、低频呼吸、眼睛一次闪烁、水脉缓流；由 CSS 处理；
- Level 2：重入攻击、暴走、三层封印、战败消散；使用有限关键帧或状态图切换；
- Level 3：资金、调用栈、余额、弱点与状态机同步；角色动作只强化证据，不决定证据。

### 角色动效约束

- 待机周期不短于 2.8 秒，位移不超过容器高度的 1.5%；
- 受击位移不超过 10 px，持续不超过 550 ms，不震动整个页面；
- 暴走残影最多三层，持续不超过 1.2 秒；
- CEI 三印每层间隔 280–420 ms，总时长控制在 2.4 秒以内；
- 战败消散完成后保留静态封印终帧，不留下空舞台；
- Reduced Motion 下直接显示每个状态的终帧，所有教学数字与文字保持一致。

## 禁止方向

- 将噬灵回环兽画成标准中国龙、西方龙、普通蛇、鱼或章鱼；
- 在不同幕次改变头骨、鳍冠、断环缺口或状态玉扣；
- 使用血液、内脏、恐怖口器或受虐式封印；
- 使用大面积金色、彩虹折射、赛博紫蓝霓虹、持续闪烁；
- 把链上节点、区块图标或钱包标志画进妖兽身体；
- 让妖兽遮挡代码、余额、调用栈、错误反馈或主操作；
- 把真实文案、地址、数值烘焙进图片；
- 以复杂实时 3D 作为 MVP 前提；
- 用 CSS 几何图形、手绘 SVG 或参考稿裁切替代正式妖兽资产；
- 把参考图中的水龙、狮兽等不一致形态继续作为正式角色。
